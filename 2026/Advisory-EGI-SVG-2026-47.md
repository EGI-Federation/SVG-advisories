## Advisory-EGI-SVG-2026-47

# HTCondor Software Suite (HTCSS) security vulnerability 

Date:      2026-10-01

Updated:   2026-11-03

## DESCRIPTION 

The HT Condor team has fixed a vulnerability which allows privilege  escalation. [R 1]


## IDs AND CVSS SCORE      

EGI SVG ID : EGI-SVG-2026-47
    
CVE ID     : N/A

CVSS Score : N/A 
    
    
## AFFECTED SOFTWARE AND VERSIONS
    
The Security release/fixed versions of HT Condor are 

24.0.24, 
24.12.24,
25.0.14, 
25.13.3

Previous versions are likely to be vulnerable 


## ACTIONS REQUIRED/RECOMMENDED

Sites are recommended to update relevant components as soon as possible 
using information in the references below.
